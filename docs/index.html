THE TRADE-OFF

          
同一张棋盘，两种哲学

        

        
不是谁替代谁，而是它们回答的问题不同。

      


      

        

          01
          
回溯法

          
系统地试，及时地退。

          
从空棋盘开始，逐行构造；一旦冲突就剪枝，走不通就撤销最后一步。它会穷尽所有可能，所以不会漏解。

          

            92 全部解
            2,056 有效结点
            O(n!) 最坏时间
          

          
适合：小规模、全部解、证明无解。

        


        

          02
          
最小冲突

          
先摆满，再修好。

          
从一个完整但可能冲突的局面出发，每次只移动一个冲突皇后，让冲突数下降。它不枚举，所以快，但不保证成功。

          

            数十步 通常收敛
            O(n) 每步检查
            启发式 非完备
          

          
适合：大规模、只要一个可行解。

        

      


      

        怎么选？
        要全部解 / 证明无解 → 回溯
        只要一个解 / n 很大 → 局部搜索
        要稳定复现 → 固定种子 + 多次重启
